# 企业知识搜索与检索增强平台企业能力

## 领域覆盖

- **知识数据源**：连接文档库、业务系统、网页和数据库
- **内容采集**：解析、清洗、切分、去重和增量同步
- **索引管理**：管理全文、向量、字段和版本索引
- **权限同步**：继承用户、组织、角色和文档访问范围
- **企业搜索**：提供关键词、语义、筛选和排序
- **检索增强**：组织上下文、引用和可配置模型适配器
- **用户反馈**：采集相关性、纠错和无答案反馈
- **检索评测**：管理测试集、召回、准确和权限泄露指标
- **搜索运营**：分析热点、零结果、延迟和索引健康

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业知识搜索与检索增强平台关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `AI_GATEWAY`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
